method 1
to add chatbot locally in your project.
-- download whole chatbot folder and add folder where your main html file exists.
-- add iframe into your main html file.
-- add chatbot's file location in iframe's src.
-- add these css properties in iframe tag

iframe {
    width: 300px;
    height: 500px;
    position: fixed;
    bottom: 10px;
    right: 10px;
}
